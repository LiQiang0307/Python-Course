# 模拟健康数据分析练习

## 一、材料和数据

- `模拟健康数据.csv`：完全虚构的数据，仅供编程教学，不对应真实人员，也不能用于医学诊断或推断真实人群状况。
- `示例程序.py`：包含四项课组任务中前三项的可运行示例；第四项请结合实际运行和修改过程撰写反思。
- `运行结果/`：示例运行生成的清洗数据、统计表、矩阵、JSON 和报告图片。

数据包含 30 个虚拟用户，日期为 2026 年 10 月 1 日至 14 日，每人每天一条，共 420 条不同记录；另有 4 条完全重复记录，共 424 行。为练习清洗，部分体重、步数、睡眠、静息心率单元格被设为空值。终端为按日期轮换模拟的采集设备，终端间差异只是描述性统计，不能解释为设备或行为造成的效果。

| 字段 | 含义 | 单位或取值 |
| --- | --- | --- |
| record_id | 记录编号 | 每条不同记录唯一 |
| user_id | 虚拟用户编号 | U001～U030 |
| date | 日期 | 年-月-日 |
| terminal | 采集终端 | 手环、手机、手表 |
| gender | 性别 | 女、男 |
| age | 年龄 | 岁 |
| height_cm | 身高 | 厘米 |
| weight_kg | 体重 | 千克 |
| steps | 当日步数 | 步 |
| sleep_hours | 当日模拟睡眠时长 | 小时 |
| resting_heart_rate | 模拟静息心率 | 次/分钟 |

## 二、运行方法

需要 Python 3.9 或以上和 NumPy、pandas、Matplotlib。进入本文件夹后执行：

```bash
python -m pip install numpy pandas matplotlib
python 示例程序.py
```

如系统使用 `python3`，请将两处 `python` 改为 `python3`。程序从脚本所在目录读取 CSV，结果写入同目录的 `运行结果`，重复运行会覆盖同名结果文件。CSV 使用 UTF-8 BOM，便于用 Excel 打开。程序会优先使用系统已安装的中文字体；若找不到，则图表使用英文标签。

## 三、任务对应关系

1. **NumPy**：身高单位换算、BMI 批量计算，比较向量化与循环结果，按步数区间计数，用广播转换矩阵，并以用户和日期构建二维步数矩阵。BMI 仅作计算练习。
2. **pandas**：读取 CSV，查看缺失和重复，去除完全重复行；数值缺失先按用户中位数填补，再用全体中位数兜底；筛选、排序、分组统计、合并；另存并读取 JSON。实际研究应根据缺失原因选择方法，不能认为填补值是真实观测。
3. **Matplotlib**：报告图包含每日平均步数折线图、终端平均步数柱状图、睡眠时长直方图和睡眠与心率散点图。分析单位是记录；因同一用户重复出现，不能把每条记录当作相互独立的个体。
4. **课组反思报告**：下方提供提纲，请用实际运行结果、个人修改和观察填写，避免把模拟数据结论写成真实健康结论。

## 四、课组反思报告提纲

- 任务目标与数据：说明数据来源是人为模拟，包含哪些字段，以及记录、用户、日期各有多少。
- 处理过程：说明如何识别重复和缺失，填补依据及其可能带来的偏差；给出清洗前后行数和缺失数量。
- 技术收获：举例解释 NumPy 数组与广播、pandas 分组与合并、Matplotlib 的图形选择；描述自己遇到的问题和解决方法。
- 结果解读：根据实际生成的图表描述变化和分布，区分描述性观察与因果结论。
- 不足与改进：讨论模拟数据的代表性、重复测量、设备差异、填补的不确定性，以及后续希望补充的验证。

## 五、可自行扩展

尝试改用不同填补方式比较结果；按用户而非记录汇总；增加年龄分组；绘制 BMI 分布或比较不同日期；练习设置坐标、图例和图形保存分辨率。
