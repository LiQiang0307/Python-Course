# 健康数据管理平台 · Pygame 完整交互版

基于 LiQiang0307/Python-Course 的 health_platform 命令行项目，复用原有 models、services、utils，新增图形入口 main.py 和gui.py。原命令行入口保留为 cli_main.py。

## 安装和运行

使用 Python 3.10–3.12，在解压后的项目目录打开终端：

```bash
python -m venv .venv
# Windows：.venv\Scripts\activate
# macOS/Linux：source .venv/bin/activate
python -m pip install -r requirements.txt
python main.py
```

macOS/Linux 如没有 python 命令，改用 python3。首次运行请注册账号；没有预设账号，也没有复制仓库中的用户、健康记录或日志。程序包含开源中文字体和许可，不需要下载图片、音乐或其他素材。

## 操作方式

- 鼠标点击左侧导航、类型按钮、提交按钮及记录详情。
- 输入框支持中文输入法；Tab / Shift+Tab 切换焦点，Enter 提交，Backspace 删除末字，Delete 清空。
- 记录列表每页6条，可用上下页按钮和滚轮翻页；记录详情和报告全文用滚轮查看。
- 录入一条体检记录后进入“健康评测”：方向键移动角色，点击场地改变位置，空格或按钮开始评测。
- 进度动画持续约2.4秒，完成后展示最新体检日期、BMI、血压、血糖、心率及体检记录数，并播放提示音。
- 左侧提示音按钮可静音；没有音频设备时自动降级。Esc 返回总览，关闭窗口退出。
- 窗口可以缩放，采用固定逻辑画布和等比例缩放，鼠标坐标同步转换。

“评测”是教学用数据汇总与交互反馈，不作疾病诊断、不建议药物剂量、不对血压血糖作医学分级。动画进度表示界面反馈过程，并非后台医疗计算进度。

## 保留和完善的功能

注册登录；体检、用药、其他记录录入；按用户、按类型查询；分类统计；CSV导出；TXT报告；当前用户记录备份；JSON持久化；异常提示和日志。

修复：日期只检查格式导致不存在日期可保存；不同体检指标与药物剂量混合统计；混合记录CSV字段不一致导致导出失败；用户创建时间加载丢失；JSON损坏被当成空数据。JSON保存改用同目录临时文件原子替换。导出对公式开头的用户文本作转义。统计中的最新值按记录日期降序选取；同日记录沿用保存顺序。

新用户密码使用带盐 PBKDF2-SHA256，原项目 MD5 密码仍可登录，并在成功登录时升级。三次密码错误后等待30秒可再试。这里只实现原项目的普通用户流程，没有新增医生/管理员权限界面。Pygame版备份当前用户记录；CLI保留原项目备份逻辑。

## 文件结构

```text

assets/OFL.txt     字体的 SIL Open Font License
requirements.txt   Pygame版本

教学对应与反思.md   知识点映射、课堂任务与反思模板

```

数据自动生成在项目 data/ 下：users.json、records.json、exports/、reports/、backups/、logs/。导出完成提示含绝对路径；备份不含密码。报告的原项目命名按用户与日期，同一天再次生成会更新该日报告。

## 迁移原 CLI 数据

先备份原目录。关闭两种程序，把原 health_platform/data/users.json 与 records.json 一起复制到本程序的 data/，保持两文件的用户ID关系。再登录原账号；不要仅复制一份文件，不要覆盖已有新数据。也可以在启动前设置 HEALTH_DATA_DIR 指向原数据目录；建议先复制副本试运行。此版本仍使用原 JSON 结构，升级后的 PBKDF2 密码只能由本版本 GUI/CLI识别，旧仓库代码不能识别升级后的密码。

单个数据目录请只运行一个程序实例；JSON文件存储没有多进程事务支持。数据仍是本地明文健康记录，请自行管理电脑与备份文件的访问权限。

## 测试

```bash
python -m unittest -vtest_app.py
```

测试使用SDL虚拟视频/音频及临时目录，覆盖注册、登录、三种记录、保存后重新读取、用户隔离、混合CSV、备份、报告、评测状态、各页面绘制、窗口缩放、中文输入事件、键鼠事件、无效日期、损坏JSON保护、旧密码升级。真实输入法和真实音频硬件还应按以下步骤手动验收：

1. 注册中文用户名，用真实中文输入法填写用药名称和备注，检查组合文字与提交结果。
2. 切换表单、键盘提交、关闭窗口，确认响应及时；检查Esc和Tab操作。
3. 在不同大小窗口点击按钮，确认命中位置；录入7条记录检验翻页。
4. 开关声音，开始评测时移动角色，确认动画期间窗口仍可操作。
5. 用表格软件打开CSV，核对三类字段；打开报告和备份，核对内容与用户归属。

如果自带字体损坏，可替换 assets/font.otf，或通过 HEALTH_FONT 指向其他合法中文字体文件。提示失败时检查底部信息及 data/logs；损坏JSON应从备份恢复，程序不会把它自动清空。
